# Sicherheitslücken

f.orga verarbeitet personenbezogene Daten und Gesundheitsdaten.

Eine Lücke nicht als Issue und nicht als Pull Request melden, sondern über die privaten Sicherheitshinweise: https://github.com/stixx200/f.orga/security/advisories/new

Angeben: Commit oder Image-Stand, was ohne Anmeldung oder mit einem normalen Konto erreichbar ist, und ob ein Echtsystem betroffen ist. Keine Zugangsdaten, keine echten Personendaten, keine Sicherungen.
