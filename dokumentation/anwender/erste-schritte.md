# Erste Schritte

## Anmelden

1. Öffnen Sie die Adresse Ihrer f.orga-Installation im Browser.
2. Melden Sie sich mit Benutzername und Passwort an – oder mit dem **Konto der Gemeinde**, falls Ihre Wehr das eingerichtet hat.
3. Nach mehreren Fehlversuchen sperrt f.orga die Anmeldung vorübergehend.

**Passwort vergessen:** Auf der Anmeldeseite „Passwort vergessen?“ wählen. Sie erhalten einen Link per E-Mail (der E-Mail-Versand muss eingerichtet sein).

**E-Mail bestätigen:** Wenn Sie Ihre E-Mail-Adresse ändern, bestätigt f.orga sie mit einem Link in der neuen Adresse.

## Profil einstellen

Klicken Sie oben auf Ihren Benutzernamen:

| Einstellung | Bedeutung |
| --- | --- |
| Sprache | Deutsch oder Englisch |
| Sammel-E-Mail | Fristen wöchentlich zusammengefasst per E-Mail |
| Passwort / E-Mail | ändern |
| Aufgabenfilter | welche Fristen auf der Startseite erscheinen |
| Zwei-Faktor | Authenticator-App einrichten |
| Angemeldete Geräte | andere Sitzungen beenden |
| Gemeinde-Konto | Verknüpfung mit dem Anmeldekonto der Gemeinde lösen |

## Zweiten Faktor nutzen

Für Verwaltung, Gesundheitsdaten und Datenschutz verlangt f.orga nach dem Öffnen einen **zweiten Faktor** (Code aus einer Authenticator-App). Die normale Anmeldung bleibt ohne zweiten Faktor. Nach der Bestätigung gilt der Faktor für eine begrenzte Zeit in dieser Sitzung.

Beim ersten Zugriff auf einen solchen Bereich richtet f.orga den Faktor ein (QR-Code bzw. Geheimnis). Ein Administrator kann Ihren Faktor zurücksetzen; danach endet Ihre Sitzung, und Sie richten den Faktor neu ein.

## Ersteinrichtung (nur Administratoren, einmalig)

Beim ersten Aufruf einer leeren Installation:

1. Einrichtungsschlüssel eingeben (steht im Server-Protokoll oder kommt von der Administration)
2. Namen der Feuerwehr festlegen
3. Erstes Administratorkonto mit E-Mail-Adresse anlegen

Danach ist die Ersteinrichtung gesperrt. Auf der Startseite zeigt f.orga Administratoren eine **Einrichtungsliste**, was noch fehlt (Adresse von f.orga, E-Mail-Versand, Abteilungen, Kataloge, Modul-Einstellungen, weitere Benutzer).

## Testsystem erkennen

Auf einem Testsystem erscheint dauerhaft der Hinweis „Testsystem – nur Demodaten“. Dort sind die Datenübernahme aus MP-Feuer und der Personenimport gesperrt.
