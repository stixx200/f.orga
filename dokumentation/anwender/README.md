# Bedienungsanleitung f.orga

f.orga ist die Verwaltungssoftware Ihrer Feuerwehr. Sie unterstützt Personal und Organisation, Einsatzberichte, Dienste, Atemschutz, Geräteprüfung, Entschädigung, Kostenersatz, Beförderungen, Kleiderkammer und mehr.

Welche Menüpunkte Sie sehen, hängt von Ihren **Rechten** und den **aktiven Modulen** ab. Rechte gelten oft nur für eine Abteilung oder für die gesamte Wehr. Die Oberfläche lässt sich zwischen **Deutsch** und **Englisch** umschalten (Profil).

## Typische Aufgaben nach Rolle

| Rolle | Typische Aufgaben |
| --- | --- |
| Mitglied | Mein Bereich, eigene Dienste, Mängel melden |
| Gruppenführer | Einsatzberichte schreiben, Personen lesen |
| Abteilungskommandant | Stammdaten und Berichte der Abteilung |
| Kommandant | Freigaben, Organisation, Auswertungen |
| Gerätewart / Atemschutzgerätewart / Kleiderwart | Geräte, Atemschutz, Kleiderkammer |
| Verwaltung / Kasse | Entschädigung, Jahresstatistik, Listen |
| Administrator | Benutzer, Rollen, Module, Einstellungen, Sicherung |
